# tree-sitter-pascal (tico's fork)

A tree-sitter grammar for Pascal: Turbo/Borland Pascal, Free Pascal and
Delphi. Forked from
[Isopod/tree-sitter-pascal](https://github.com/Isopod/tree-sitter-pascal)
v0.10.2 (MIT, copyright Philip Zander; see `LICENSE`), which is the grammar
Helix and nvim-treesitter use and is also published on crates.io as
`tree-sitter-pascal`.

It's vendored here rather than pulled from crates.io because upstream is
aimed at Delphi and modern Free Pascal, and has no rule for several
constructs that are everywhere in Turbo Pascal 7 code. Each addition is
marked "tico" in `grammar.js`:

- subrange types on their own or after `set of`: `1..10`, `'a'..'z'`,
  `-MaxInt..MaxInt`, `Low(T)..High(T)` (`declSubrange`; upstream only
  accepted a range inside `array[...]`)
- control-character string literals, `^G` and `'x'^M^J` (`literalCaret`,
  a `literalString` child like `#13`)
- an upper-case exponent marker, `1.5E10`, `1E3`
- the standard-Pascal program parameter list, `program X(input, output);`
- `absolute $SEG:$OFS` alongside `absolute NAME`
- unsigned-integer labels: `label 10;`, `goto 10`, `10:`
- a label right before `end` (`Done: end`), which upstream rejected even
  for identifier labels
- Free Pascal's binary and octal literals, `%1010` and `&777`
- Free Pascal's `otherwise` as a synonym for `else` in `case`
  (`kOtherwise`)

Inline assembler (`asm ... end`) parses as one opaque `asmBody`, as
upstream, with no highlighting inside it.

## Files

- `grammar.js` — the grammar; the only file to edit by hand
- `src/parser.c`, `src/grammar.json`, `src/node-types.json`,
  `src/tree_sitter/*.h` — generated by `tree-sitter generate`, ABI 15
- `test/corpus/` — upstream's corpus plus `turbo-pascal.txt` for the
  additions above; `tree-sitter test` runs them
- `LICENSE` — upstream's MIT license
- `tree-sitter.json` — upstream's grammar metadata, kept for the CLI

tico's `build.rs` compiles `src/parser.c` directly with the `cc` crate,
and `src/syntax/languages.rs` declares the `tree_sitter_pascal` entry
point. The highlight query lives with the others in
`src/syntax/queries/pascal.scm`.

## Regenerating

After editing `grammar.js`, regenerate the parser with the tree-sitter
CLI (0.25 or newer) and a JavaScript runtime it can find (`node` by
default), then run the corpus and tico's tests:

```sh
cd grammars/tree-sitter-pascal
tree-sitter generate
tree-sitter test
cd ../..
cargo test syntax
```

`tree-sitter parse FILE.pas` from the same directory prints the tree for a
sample file, which is the quickest way to check a new construct; the
`syntax::tests::pascal_turbo_pascal_dialect_parses_and_highlights` test
keeps a Turbo Pascal sample that must parse without a single `ERROR` node.
